# Onboarding Frontend

## Setup

```bash
cd frontend
npm install
```

## Run Dev Server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Features
- Modern UI with TailwindCSS
- 3-column comparison table (CDD, Companies House, Customer System)
- AI Assistant sidebar (conflicts, missing, recommendation)
- Responsive design

## API
- Expects backend at `http://localhost:8080/api` (configurable via `REACT_APP_API_URL`)
